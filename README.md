# Wand & Widgets marketing assets

Screenshots, banners, and other promotional images for Wand & Widgets modules. The Foundry package pages use the public files in this repository.

For installation and support, visit the relevant module's Foundry package page.

## Usage

Use a file's existing public URL when embedding it. Keep published filenames and paths stable so package pages continue to display their images.
