# Mortal Needs 3.0.2

Images for the [official Foundry package page](https://foundryvtt.com/packages/mortal-needs).

- `hero.jpg`: title artwork using the module's seal and need icons.
- `needs.jpg`: the fourteen built-in needs.
- `company.jpg`: GM and ordinary-player views, captured in Foundry VTT.
- `condition.jpg`: a configured Cold consequence and recovery guidance.
- `story.jpg`: a narrative chat card sent from the dock.
- `presets.jpg`: an illustrated guide to the five built-in presets.

The interface captures show Mortal Needs 3.0.2 in Foundry 14.368 with D&D 5e 6.0.5. Rowan, Mira, and Bram are demonstration characters. The pictured consequence is an example configuration, not a mandatory rule. Interface captures are cropped and enlarged for presentation. The preset guide is an explanatory graphic, not a screenshot of the configuration window.
